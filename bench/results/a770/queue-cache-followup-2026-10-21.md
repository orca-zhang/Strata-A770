# A770：队列与缓存后续对照（2026-10-21）

本轮未确认新的稳定整模型收益，六组候选均未采用。正式源码、用户配置和生产 EXE 本轮未改；候选留在独立实验目录。

硬件：Arc A770 16 GB、Xeon E5-2696 v4、PCIe 3.0、Windows 10，驱动 32.0.101.9034。工具链：DPC++ 2025.3.2、oneMKL 2025.3、Level Zero SDK 1.33.1。系统电源计划为平衡；未修改全局电源设置或停止其他进程。

## 整模型解码结果

数值是相邻两个原设置 A 的解码耗时几何均值除以候选耗时，再减一；正值表示吞吐提高。每行只有一次候选筛选，未进行成功方案的重复确认。基线漂移另列，不能把小幅正值直接认定为收益。

驻留表提前上传出现明显单场景回退；每两轮换入一次的微小正值伴随较大基线漂移，不作为提速结论。静态批量提交第二条提示的回退发生在前后基线几乎一致的条件下，也不采用。

## 测试方法与范围

使用 IQ2_XS 模型，请求专家缓存 4000，INFO 实际均为 4191 槽；adapt-swaps=32、adapt-every=1、adapt-decay=0.5 为对照。三条提示长度为 2048、2048、8000 token。每个独立进程先对三条提示各生成 128 token 预热，再各生成 128 token 计时；prompt-cache=0，专家缓存继续自适应，未开启额外解码诊断。

换入量顺序为 32/16/32/8/32；提前上传和换入频率为 A/提前上传/A/每两轮换入/A；原生队列为 A/固定批量/A/驱动内排序/A。所有 GPU 测试串行并持有实验锁。

队列测试均使用同一个最终私有 EXE：固定批量同时设置 UR_L0_BATCH_SIZE=64 和 UR_L0_COPY_BATCH_SIZE=64；驱动内排序仅设置 UR_L0_USE_DRIVER_INORDER_LISTS=1。只改变子进程环境，未写入用户配置。

即时命令列表同时设置 UR_L0_USE_IMMEDIATE_COMMANDLISTS=1 和 UR_L0_USE_DRIVER_INORDER_LISTS=1。三条各 32 token 的功能短测通过，但三条提示均明显慢于另两组短测，因此未进入完整性能对照，未给出其整模型收益百分比。短测不是相邻基线配对。

15 个完整测试进程及 3 个功能短测共 11808 个输出 token，包含预热，均与原始最终 EXE 的参考输出一致。提前上传版本另检查待提交驻留表快照与 CPU 最终表一致；未触发断言或超时。

提前上传只在独立构建中增加实验开关 STRATA_ADAPT_RES_UPLOAD_EARLY，默认关闭；在已有专家拷贝队列末尾上传驻留表，并保留同一个完成事件和提交检查。A/B 使用同一候选 EXE，只切换开关。候选基于 10 月 19 日冻结引擎与头文件、最终 IQ 内核对象；不是对当前全部脏工作区的重新构建。

预填充原始时间和相邻对照已包含在 JSON；部分场景漂移较大，本轮不发布稳定预填充提速结论。Q2 默认整模型基线已有停顿和重复输出不一致问题，本轮未重跑，也不外推 IQ2 的结果为 Q2 收益。
