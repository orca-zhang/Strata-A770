# 完整 HC 链：固定布局，切换 1／48 组权重工作集

2026-11-07，Windows 10，Arc A770 16GB，驱动 32.0.101.9034，Xeon E5-2696v4，oneAPI 2025.3.2，VTune 2026.4。
同一 full-current 冻结头、Host 内核库、运行库、Direct 驻留诊断对象与 HC128 原生包；不重编数学内核。

每个进程都预先独立分配 48 组内容相同的 down/up/inject BF16 权重，合计 603.785 MiB（含 guards）。
bank 在这里指缓冲组，不代表 DRAM 通道或已测得的物理页映射。
容量按请求的缓冲大小统计，不包含驱动页对齐和驻留开销，不是实测物理显存占用。
四个图共用这些分配及同一输入／输出地址，仅切换访问 1／48 组权重以及每列表 48／192 次 HC read。
每次 read 是 norm→down-sliced→reduce→up/Q8；实际录制后断言每图 192／768 个 kernel 节点。
1 组图只触碰 bank0；48 组图按轮转覆盖所有组。每组数值相同，未使用真实模型层权重、跨层输入递归或真实中间张量。
这个设计保持进程分配布局相同，用于检验缓存工作集；工作集变化也可能影响频率，不能单凭耗时认定某级缓存为根因。

固定 T4、残差开、Q8，复用独立 CPU FP64 参考、独立 Q8 量化器对照。
每次 RUN 都回读完整输出、全部 48 组权重及输入，校验所有内容与 guards；完整输出 hash 还与此前单组 HC 探针一致。
无 GPU 时间戳；Host steady-clock 仅包围 replay 与每列表等待，清零、回读、校验和打印在计时外。
每个样本为 24,576 次 HC read／98,304 次原生派发，四种组合在每进程中交错。
每臂新进程，L0→Direct→L0；每组合预热 49,152 次 read，采集前／中／后各测三次，采集中采用反向交错顺序。
每组合六个不带 profiler 的样本取中位数，外侧 L0 中位数取几何均值；全部 120 条协议、12,976,128 次派发保留。
