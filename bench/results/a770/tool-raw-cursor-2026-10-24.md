# 原始工具参数的增量扫描游标（2026-10-24）

本轮继续[流式参数偏移优化](tool-stream-offset-2026-10-24.md)。原始 JSON 参数尚未结束时，扫描器原来会从值的开头重复查找结束标签。现在单独保存搜索位置：没有完整候选、且已经检查了至少一个标签长度时，跳过已排除的正文，末尾保留 11 个字符以覆盖跨块的 `</parameter>`。候选的后继尚未确定时保留原起点，避免漏掉它。参数值的起点保持不动，完整值仍用于原来的 JSON 解析。

生产代码只增加一个游标及其推进条件，另加一个回归测试。没有新增依赖、正则或原生接口，继续复用现有 SIMD 扫描器，原生源码和二进制不变。该游标减少重复查找；缓冲区拼接、边界复查和参数解码仍然存在，不能声称整个解析器零拷贝或线性复杂度。

两轮完整 CPU 解析计时中，原生路径的含文字终止符及 JSON 转义 Unicode 数组耗时下降 **36.3%～37.3%**，含真实中文的密集符号数组下降 **27.8%～28.9%**，含中文和 emoji 的密集符号数组下降 **31.8%～33.2%**。ASCII 密集符号数组只有第一轮通过漂移规则，下降 19.04%；第二轮弃用，未当成两轮有效收益。

Python 回退路径中，含文字终止符的数组下降 **61.0%～63.9%**，ASCII 密集符号数组下降 **36.8%～37.9%**，中文密集符号数组下降 **22.4%～25.6%**。中文与 emoji 数组两轮均未通过漂移规则，没有据此宣称回退路径的收益。这些都是合成输入，未测真实请求的参数数量、值长度和符号密度分布。

普通输入没有明确收益。1,000 个短参数分块输入，原生只有第二轮有效、慢 1.51%；Python 回退两轮慢 1.43% / 1.63%。约 1%～2% 的小幅变化按实用噪音口径解读，原始数据保留，不继续追测这些小差异。控制项也有较大的单轮变化：普通回答原生第一轮 +4.27%，Unicode 字符串回退第一轮 +4.65%；后者第二轮 +0.19%。这些路径不进入新增的 raw 增量扫描分支，未确定差异根因，不能声称每种输入都更快。

Windows 10 19045、Xeon E5-2696 v4、CPython 3.11.9 x64，固定逻辑 CPU 42。比较本轮修改前后的冻结模块，基线已包含前几轮优化。计时包含创建解析器、全部 feed、事件收集和 finish；分块构造与正确性断言位于计时外。每轮交错执行 7 组 A/B/A，B 中位数对比两个 A 中位数的几何平均；A 漂移绝对值超过 3% 弃用。该阈值不是置信区间，也不能排除所有干扰；负值表示耗时下降。

原生相关测试 99 项通过；Python 回退 96 项通过、3 项原生专项跳过。新增一个回归测试，按 1～16 字符分块并插入空 feed，覆盖无效文字终止符、跨块终止符、待定后继、Unicode 空白、原始 JSON 和紧接的字符串参数，以及流式参数、最终参数和调用 ID 的一致性。12,432 组流式差分逐次 feed 和 finish 的事件及状态一致；2,000 组参数直接解析差分一致（含 966 个相同的预期损坏输入异常）；10,000 组调用结束位置差分一致，共 24,432 组。

首个原型在每次失败检查后都更新游标，并用 rfind 重新定位待定候选。1,000 个短参数分块输入，原生两轮慢 5.43% / 3.95%，Python 回退慢 3.21% / 4.98%，因此撤回该方式。最终版只在可以跳过旧正文时更新，候选后继未定时保留当前起点，不再调用 max 或 rfind。原型、两轮样本和冻结源码保存在 `build-sycl-a770-raw-cursor-20261024/`；最终源码、计时样本及测试日志保存在 `build-sycl-a770-raw-cursor-final-20261024/`。[机器可读记录与 SHA-256](tool-raw-cursor-2026-10-24.json)可复核冻结源码、测试和计时算术。
