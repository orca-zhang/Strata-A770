# U4×S4：全层原生 repack 与 BF16 inject 保留方案（2026-10-26）

**完成了全层离线候选转换，尚未获得新的完整 HC 或模型提速。** 扩大到全部 97 组 HC 后，三项乘积近似的 lo/mixed 检查全部通过；inject 的误差暴露了三组样本筛选的局限。下一版候选保留 BF16 inject，并继续融合 down 归约、SiLU、S4 打包及 up 消费步骤。

## 原生 sidecar 已生成

从现有 IQ2_XS pack 内**原始 BF16 HC**直接转换。专家权重没有参与，输入不经过 Q2/Q8。97 个 down 与各自 4 行 inject 合并成 328 行原生 B 排列，包含 4 行零填充；最终 mixer 无 inject，补 8 行零。97 个 up 按原生 B 排列写出。每个权重包含两层 U4 残差，8 payload bits 加 FP32 group64 scale，仍是 9 bits/weight。

| --- | ---: | ---: |
| 原始 BF16 down/up/inject | 1,279,262,720 | 1220.00 |
| 194 个 U4 原生文件，含 padding/header | 724,107,328 | 690.56 |
| 加上 96 个原始 BF16 inject sidecar | 731,971,648 | 698.06 |
| 保留 BF16 inject 后的文件差额 | 547,291,072 | 521.94 |

全部 194 个 U4 文件及 96 个 BF16 inject 文件已读回核对大小、SHA256、原生解码、scale 有限性和零填充；权重逐矩阵记录误差。这是实际磁盘负载变化，**没有测量 VRAM 节省**，也不是能由当前模型 loader 直接运行的新模型。

没有放宽预先固定的 1% 权重 NRMSE 筛选：290 个矩阵有 79 个失败，分别是 down 2/97、up 46/97、inject 31/96。各类最坏误差为 1.0282%、1.3120%、1.5400%。首个 inject 超限时的转换中止也写入记录；随后保留原门槛及已有文件的逐字节一致性检查，完成文件生成和失败清单。保留 BF16 inject 后，仍有 48 个 down/up 未过该权重门槛，不能宣称转换已被质量验收。

## 全层 CPU 激活检查

使用 NumPy 2.4.6、FP32 矩阵乘与 FP64 RMS 归约，从**实际写出的 sidecar**解码。覆盖全部 97 个原始 BF16 HC 对；T1/4/6/8、apply0/1、普通/0.001 倍微小/每 256 元素一个 16 倍离群输入，检查 lo/mixed/inject，共 27,840 格。随机序列和门槛与[三组 CPU 筛选](u4s4-hc-cpu-2026-10-26.md)一致。

四项计算为 `(W0+W1)(X0+X1)`；三项计算省去 `W1·X1`。每个 group 的 DPAS 静态次数由 4 降到 3；**减少 25% 次数不代表提速 25%**。

| 替换范围 | 项数 | 通过格数 | 失败的 HC 对 | 失败字段 |
| --- | ---: | ---: | ---: | --- |
| 仅 up | 4 | 6960/6960 | 0/97 | 无 |
| 仅 up | 3 | 6960/6960 | 0/97 | 无 |
| down/up/inject | 4 | 6940/6960 | 15/97 | 全为 inject |
| down/up/inject | 3 | 6883/6960 | 41/97 | 全为 inject |

up 单独替换时，lo/inject 没变；mixed 单独为每方案 **2328/2328**，三项方案普通/微小最坏 NRMSE **3.2212%**，离群最坏 **4.2271%**。down/up 一起替换时，lo/mixed 也全部通过：每方案 **4656/4656**，三项方案 lo/mixed 最坏分别为 **6.8981%/7.3864%**，均出现在允许 10% 的离群输入中。量化 inject 最坏误差为四项 **22.6141%**、三项 **25.1313%**。

因此，保留小体积 BF16 inject 是下一候选的明确选择。它不会改变本检查中独立计算的 lo/mixed，但真正混合路径还需 GPU 验证；本记录没有把推导当成已测 GPU 结果，也没有用激活代理门槛抹掉上述 1% 权重筛选失败。没有真实模型激活、固定目标 logprob/PPL 或生成质量验收。
