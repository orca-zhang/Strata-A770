# A770：PCIe 与专家缓存后续测试（2026-10-21）

本轮继续筛选减少 PCIe 开销的方法。未确认新的稳定整模型提速，未修改生产 EXE、用户配置或正式源码。

硬件为 Arc A770 16 GB、Xeon E5-2696 v4、PCIe 3.0、256 GiB DDR3，Windows 10，驱动 32.0.101.9034。工具链为 DPC++ 2025.3.2、oneMKL 2025.3、Level Zero SDK 1.33.1。

## 先搬入显存再计算

使用上一轮最终 IQ 内核对象和真实专家权重，对照直接读取映射内存、GPU copy kernel 中转、原生 memcpy 中转。每格式采用 A/中转一/A/中转二/A，T=1/4/6，计时覆盖搬运和 gate/up → SwiGLU/Q8 → down。暂存指针预先初始化，memcpy 使用连续源，是偏向中转方案的条件；实际路由专家可能分散。

| GU 格式 | GPU 中转吞吐变化 | 连续源 memcpy 吞吐变化 |
| --- | ---: | ---: |
| IQ2_XXS | -7.42%～-1.82% | -7.25%～-1.35% |
| Q2_0 | -3.68%～-2.88% | -4.15%～-2.88% |
| IQ2_S | -4.63%～-3.97% | -4.47%～-3.91% |

12 个回读进程共 432 次完整专家链逐位对照通过，含散布写入、边界检查和三种网格。中转均变慢，未接入运行时。

## 现有缓存参数

IQ2_XS 使用同一个最终私有 EXE。请求缓存 5500，INFO 实际均为 5771 槽。换入量测试为 32/64/32/128/32；衰减测试为 0.5/0.75/0.5/0.9/0.5。均排除首条 2K、16 token 预热，再测 2048/2048/8000 token 三条提示。换入量测试每条输出 64 token，统一开启解码诊断；衰减测试输出 128 token，无额外诊断。

| 参数候选 | 三提示吞吐变化几何均值 | 单场景变化范围 | 相邻基线最大耗时漂移 |
| --- | ---: | ---: | ---: |
| adapt-swaps=64 | +0.55% | -2.14%～+2.74% | 2.71% |
| adapt-swaps=128 | -1.25% | -3.57%～+0.75% | 5.90% |
| adapt-decay=0.75 | +6.23% | -1.31%～+13.79% | 40.43% |
| adapt-decay=0.9 | +0.75% | -1.86%～+5.82% | 12.88% |

以上为筛选观察值。64 次换入的收益不足且 8K 回退；128 次换入也回退。衰减测试出现较大基线漂移，不能将表中正数认定为提速，均未采用。缓存容量不同于上一轮的 4191 槽，禁止跨容量计算参数收益。

诊断显示首个 32/64 对照中，三条计时请求的 VRAM 路由命中率分别为 74.66% → 78.78%、82.39% → 85.66%、83.71% → 83.81%。命中率改善未转化为稳定的综合提速。

## 只统计已接受 token 的路由

候选在验证完成后，从输入 token 与输出 token 找到已接受前缀，仅将该前缀的路由用于缓存换入评分。实际计算、FP32 累加、路由诊断和 trace 仍覆盖原窗口。实验开关为 STRATA_ADAPT_ACCEPTED_ONLY；正式源码中未加入该开关。

为隔离策略，使用冻结的 10 月 19 日 verify 源码和头文件重新编译一个对象，复用对应 main 和引擎库及最终 IQ 对象。A/B 使用同一个私有 EXE，只切换实验开关；不是当前整个工作区的重新构建。缓存请求 4000，实际 4191 槽；不与 5771 槽结果比较。

A/B/A/B/A 五个独立进程，每进程先将三条提示各生成 128 token 预热，再将三条提示各生成 128 token 计时。prompt-cache=0，每次重新 prefill；专家缓存继续自适应。每个 B 按相邻 A 解码耗时的几何均值配对。

| 提示 | 第一组吞吐变化 | 第二组吞吐变化 | 两组几何均值 | 最大基线耗时漂移 |
| --- | ---: | ---: | ---: | ---: |
| 2K A | -2.52% | -0.41% | -1.47% | 0.89% |
| 2K B | +0.24% | -0.32% | -0.04% | 3.64% |
| 8K | -0.52% | -1.25% | -0.89% | 1.43% |

三场景吞吐比的几何均值为 -0.80%。下列合并速度另按每进程三次解码的总耗时计算，不能与几何均值混用。

| 配对 | 基线 tok/s | 候选 tok/s | 合并吞吐变化 | 基线耗时漂移 |

五进程共 1920 个计时输出 token、1920 个预热输出 token，逐 token 一致，且与原始最终 EXE 的相同提示输出一致。未确认稳定收益，候选只保留在实验目录。
