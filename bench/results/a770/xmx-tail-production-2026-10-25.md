# A770 XMX 尾块优化：生产切换验证（2026-10-25）

本文保留尾块版当时的切换结果；后续生产版另已通过[专家链批量提交验证](xmx-batch-production-2026-10-25.md)，本机启动配置已更新至该版本。下文测量和快照保持原记录。

独立固定容量 A/B/A 与实际自动缓存兼容检查均通过，**本机启动配置已切换至尾块优化 EXE，下次启动服务生效**。2,069-token 检索请求的 HTTP 配对基线为 **55.608 秒**，候选中位数为 **41.443 秒**，耗时下降 **25.47%**；等效 prefill 从 **38.34 提升至 51.90 tok/s（+35.34%）**。1K 和工具差异按噪音处理，未确认 decode 提升。

## 改动与测量条件

本轮复用[首轮尾块优化](xmx-tail-2026-10-25.md)中已通过 1728 项检查的冻结 EXE，补足长输入预热，并将性能对照与自动缓存兼容检查分别完成。候选仅改变对齐输入的 XMX 补齐：完整行块直接读原输入，最后不足 8 行的部分单独复制并补零。BF16 `T=2068, K=10240` 的补齐空间从 **40.46875 MiB 降至 160 KiB**，保留原 32 MiB 工作区。FP16 / BF16 输入、FP32 累加、原 XMX 运算顺序及队列等待不变，未对齐步长仍保留整块复制与回退。

硬件为 Arc A770 16 GB、Xeon E5-2696 v4、256 GiB DDR3、PCIe 3.0 ×16；Windows 10、驱动 32.0.101.9034、oneAPI DPC++ 2025.3.2 / oneMKL 2025.3。使用 Qwen3.8-Flash-Next IQ2_XS、FP16 KV、MTP4、prefill / context 8192、`--short-read 1024`，temperature 0，关闭 thinking 与提示缓存。本地 Anthropic `/v1/messages` 非流式接口排除启动时间，生成的工具调用不执行。

基线为已部署的基本 XMX EXE，候选为同一组冻结生产对象中仅替换 GEMM 对象的私有构建，匹配 32 MiB prefill 对象及 ABI。没有同时开启专家链、跨专家提交、HC inject 或 GDN 试验开关。本轮没有重建整个当前工作区。

## 固定容量 HTTP 对照

顺序为旧版 A1 → 候选 B → 旧版 A2，分别启动新服务，均请求 5500 个专家缓存槽位，实际均为 **5771 slots / 7.74 GiB**。每服务固定预热三次 255-token 工具，再各预热一次原工具、1K、2K；随后按 **1K → 2K → 原工具** 交替三组。没有重试或择样。下表基线为 A1、A2 各自中位数的几何平均，候选为三个正式样本的中位数。

| 场景 | 输入 / 输出 tokens | 等效 prefill tok/s | decode tok/s | HTTP 完整响应 |
| --- | ---: | ---: | ---: | ---: |
| 原工具基线 | 258 / 276 | 22.16 | 25.96 | 22.337 秒 |
| 原工具候选 | 258 / 276 | 22.22 | 26.37 | 22.192 秒 |
| 1K 基线 | 1038 / 23 | 38.64 | 16.02 | 28.307 秒 |
| 1K 候选 | 1038 / 23 | 38.59 | 16.06 | 28.369 秒 |
| 2K 基线 | 2069 / 25 | 38.34 | 15.50 | 55.608 秒 |
| 2K 候选 | 2069 / 25 | **51.90** | 15.90 | **41.443 秒** |

候选 HTTP 完整范围：原工具 22.092～22.411 秒，1K 28.031～28.392 秒，2K 41.130～41.933 秒。范围为最小至最大值，不是置信区间。2K 候选 prefill 中位数为 39.869 秒，decode 为 1.572 秒；各指标独立取中位数。HTTP 包含模板、分词、引擎计算和完整响应处理，等效 prefill / decode 分别以输入量 / 输出量除以对应引擎时间。

| 对照 | HTTP 吞吐变化 | prefill 吞吐变化 | HTTP 基线漂移 | prefill 基线漂移 |
| --- | ---: | ---: | ---: | ---: |
| 原工具 | +0.654% | +0.286% | +1.176% | +0.282% |
| 1K | −0.218% | −0.129% | −0.255% | −0.168% |
| 2K | +34.182% | +35.341% | −0.556% | −0.544% |

吞吐变化为 `基线耗时 / 候选耗时 - 1`，漂移为 `A2 / A1 - 1`。原工具的 276-token decode 另行纳入回退检查：基线漂移 +2.891%，候选吞吐 +1.573%，通过门槛。短检索的 decode 变化仅作描述；本轮没有确认持续 decode 提升。不同预热与请求顺序的实验不直接比较绝对 decode 数字。

测量前冻结的采用条件全部满足：三个场景完整响应一致；所有 HTTP / prefill 及原工具 decode 控制的基线漂移绝对值不超过 3%，吞吐回退不超过 3%；至少一个长输入的 HTTP 或 prefill 吞吐改善达到 3%。**27 次正式请求全部正确，同场景完整响应删除随机消息 / 调用 ID 后一致**，包含用量、停止原因及工具参数。

## 实际自动缓存检查与切换

性能门槛通过后，在同一次 GPU 预约内另开候选服务，恢复生产 `--expert-cache auto`，实际为 **6319 slots / 8.47 GiB**。一次短工具预热后，各检查一次原工具、1K、2K；三次完整响应均与正式候选一致。

| 自动缓存兼容检查 | 输入 / 输出 tokens | 等效 prefill tok/s | decode tok/s | HTTP 完整响应 |
| --- | ---: | ---: | ---: | ---: |
| 原工具 | 258 / 276 | 21.82 | 24.51 | 23.092 秒 |
| 1K | 1038 / 23 | 37.33 | 16.14 | 29.269 秒 |
| 2K | 2069 / 25 | 50.77 | 15.60 | 42.391 秒 |

自动缓存表为单次兼容检查，预热与容量均不同于正式对照，不用于推断性能增量。本轮共 **49 次 HTTP 请求全部通过**，包含 18 次正式阶段预热、27 次正式测量、一次自动缓存预热及三次兼容检查；全部 `cache_n=0`，四个私有服务均以退出码 0 结束。

通过离线复核后，本机 `strata-iq2_xs.json` 仅原子更新 `exe` 与匹配的 `env.STRATA_SYCL_BIN`。`STRATA_PREFILL_NATIVE_XMX=1`、自动缓存、FP16 KV、MTP4、`--short-read 1024` 和其余设置保留原值，**下次启动服务使用新 EXE**。旧配置原始字节保存在本机实验目录的 `measure/production-config-before.json`，新配置另存快照，两侧 SHA256 已纳入摘要。
