# A770 IQ2_S: same-size row field arrays

A77016GB / PCIe3.0, Windows, driver32.0.101.9034, DPC++2025.3.2. The previous native mapped-weight profile reported high GU stalls; the84-byte padded-block screen regressed while increasing storage. This candidate rearranges each820-byte IQ2_S row into640 code/sign bytes,80 high-code bytes,80 scale bytes and20 FP16 block-scale bytes. Main code/sign reads become aligned32-bit loads. Row size remains820 bytes and complete expert size1510400 bytes. Arithmetic, scales, dots, reduction order, down weights and precision are unchanged.

This prototype is restricted to N2560/F640, paired IQ2_S GU16/SG16 and Q2_0 down4. It does not implement generic widths or fallback paths. Every candidate process inverse-transforms and compares all240 real expert blobs byte for byte before timing. Repack initialization is excluded from operator timing; no smaller storage or model-capacity saving is claimed.

Five fresh A1/B1/A2/B2/A3 processes use eight physical mapped-host sets and T1/4/6. All360 full-chain output/guard checks and15 graph-output checks must pass the frozen reference. All165 batches are retained: perT,16 warm graph48-chain replays followed by11 batches of4 replays. The unchanged baseline worker/executable/reference is reused; candidate worker changes only untimed layout setup. GPU/compiler access uses the shared lock and no profiler.
