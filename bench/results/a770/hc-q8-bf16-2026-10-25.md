# A770 HC Q8 weight-read prerequisite

Measured on A77016GB / PCIe3.0, Windows, DPC++2025.3.2. This is a lossy weight-representation and operator experiment. No engine/default, production executable or configuration changed; no full-model quality, Decode tok/s or actual VRAM-saving measurement exists. The 40tok/s goal is not achieved.

The actual IQ2_XS GGUF stores all194 HC down/up matrices as BF16. There is no original Q8_0 representation to reuse losslessly. Quantizing the current packed BF16 values to reference Q8_0 and decoding with BF16 RNE passes the predeclared per-tensor relativeL2<=1% and maxabs<=1% of its own maximum weight. All194 matrices are scanned; every tensor retains source/Q8/reconstructed hashes and errors.

Maximum weight relativeL2: 0.840103%; maximum normalized absolute error: 0.578035%. Raw storage is1212.5MiB BF16 versus644.140625MiB Q8_0, a theoretical568.359375MiB difference. The operator workers keep original BF16, decoded BF16 and Q8 in BOTH arms; this experiment does not realize that saving.

The isolated candidate changes only weight loads in the frozen SG16 sliced-down/up HC kernels. It reconstructs BF16 bits from Q8_0 before the unchanged FP32 dots. CPU-decoded BF16 supplies a separate exact GPU implementation oracle; original BF16 supplies the quantization-error comparison. Three real pairs (layer0 attention/FFN and final mixer), two seeded synthetic input scales, apply0/1 and T1/2/4/6/8 exercise complete outputs, normalized activations, guards, unused rows, read-only inputs and graph output. These are synthetic activations, not a representative hidden-state corpus.

Both cohorts use fresh A1/B1/A2/B2/A3 processes and a new reference capture. Shared GPU/compiler lock, frozen runtime, no profiler. T1/4/6 graph48 calls rotate three real pairs;16 warm replays then11 batches of4 synchronous replays. All330 batches and1530 counted output/guard checks are retained. Setup/repack is excluded. lo and mixed are assessed separately: normal relativeL2<=5%,cosine>=0.995; small-input stress<=10%,cosine>=0.98. Maximum absolute errors are retained.

The original screen requires all six pairs>=3% gain and<=3% baseline drift; it remains FAILED. A new independent confirmation predeclares>=1% for all six pairs with the same drift/precision checks. This does not rewrite the original gate.
