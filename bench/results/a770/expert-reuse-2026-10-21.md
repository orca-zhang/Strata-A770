# A770：Q2 gate/up 激活复用（2026-10-21）

在上一轮已采用的 [Q2 打包读取](q2-packed-load-2026-10-21.md) 基础上，Q2_0 显存专家链延迟进一步下降约 15%–16%。采用的改动仅复用已有 IQ2_S 成对 gate/up 内核，让 Q2 共用一次 Q8 激活解码；保留 Q2 的整数点积、缩放和 8 lane 浮点归约顺序。没有新增依赖或运行开关。

基线已经包含上一轮的打包读取，本表表示额外收益。IQ2_S 和 IQ2_XXS 的变化均在 0.6% 以内，未测得明显收益。

Q2_0 使用 `strata-q2_0.json` 的默认 GU8 / Down8；IQ2 使用 `strata-iq2_xs.json` 的 GU16 / Down4，每次启动先清除继承的 `STRATA_*` 环境再加载对应配置。Q2 新路径限定于 A770、`n_embd=2560`、GU8、grouped v2，旧内核和 split 模式仍走原有派发。

计时覆盖完整 gate/up、SwiGLU/Q8、down，激活量化在计时外。权重来自 IQ2_XS 的 layer 0（IQ2_S）、layer 1（IQ2_XXS）及 Q2_0 的 layer 0，每种格式 240 个真实专家，分成八组、每组 30 个。激活为固定种子的高斯样本；1 / 4 / 6 token 对应 10 / 20 / 30 个专家组、10 / 40 / 60 个条目，多 token 计时每组两个条目，不代表真实路由碰撞分布。

普通 in-order SYCL 队列捕获 48 次完整调用，循环八组专家。每个阶段预热 16 次图，测 11 批、每批重放四次图，取批次中位数，计入主机提交和等待。两份独立 EXE 分别链接当前基线与最终候选 IQ 对象，不经过实验类型或模式派发。每种格式执行 A/B/A/B/A/B/A 七个新进程；每个 B 对应相邻 A 的几何均值，再分别取三组基线和候选耗时的中位数。前后基线最大漂移 3.53%，未删除任何样本。

## 正确性和未采用的方案

- 最终候选完成显存 648 组、映射内存 216 组真实权重的完整输出逐位一致比较，覆盖八组专家、三个 `grid_groups` 和三种输入大小；含非零条目起点、分散输出位置、未使用输出和两侧哨兵。另核对 36 次图计时结束后的输出。
- 既有 `native_grouped_parity` 增加一行 Q2_0 的 2560×640 模型形状检查。在 Q2、IQ2 两套配置下共完成 9,744 次与 v1 的逐位一致比较，均为零失败；覆盖各格式、空调用、不同分组长度、尾部条目、非零起点、分散输出、陈旧 scratch 及不同 `grid_groups`。Q2 新路径使用实际 GU8 设置验证。
- IQ2_XXS 的权重解码复用在每组两个条目的多 token 测试中快约 14%–21%，但单 token 三次复测慢约 1.1%–7.0%。仅保留两个条目复用的版本仍有单 token 回退，未采用。IQ2_XXS 成对 gate/up 的单 token 回退约 28%–31%，也未采用。所有试验和样本保存在 JSON。
- 本轮没有重新测整模型 token/s、生成等价性或困惑度。上一轮 Q2 基线自身不可重复的问题仍未解决，不能把这里的专家链逐位一致当成整模型生成验证；见 [上一轮记录](q2-packed-load-2026-10-21.md)。
- 源码已采用，生产 EXE 和用户配置未替换。计时与回归程序直接链接最终 IQ 对象；回归程序的其他内核复用 2026-10-19 的库，没有重建整个仓库。
