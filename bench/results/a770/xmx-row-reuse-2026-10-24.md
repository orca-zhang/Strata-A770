# A770 XMX 行复用：算子提速，整模型未通过

本轮未合入行复用，现有 XMX 源码、生产 EXE 和配置保持原样。大矩阵算子有约 2.1× 的局部收益，但最终 IQ2_XS 整模型确认中，有效回合的预填充增量只有 **+1.63%**，未达到预先设定的 3%；另一回合基线漂移超限。

硬件为 A770 16 GB、E5-2696 v4、PCIe 3.0 x16、Windows、驱动 32.0.101.9034、DPC++ 2025.3.2、oneMKL 2025.3。基线是已经接入的直接 XMX R1，包含当时已有的权重转换向量化。这里报告相对 R1 的增量，不与上一轮相对 FP32 widening 的倍数相乘。

候选和检查代码保存在[未应用的补丁](xmx-row-reuse-candidate-2026-10-24.patch)中；逐形状数值、失败门槛及构建哈希见[数值摘要](xmx-row-reuse-summary-2026-10-24.json)。

## 方法与筛选

原内核每个子组计算一个 8×8 输出块。R2、R4 分别保留两个、四个独立 FP32 累加块，同一次权重块读取服务 16、32 行。输入仍为 FP16 或原生 BF16，输出仍为 FP32，没有降低累加精度。

全局 R2 在所测 1280 列形状回退最多约 5.78%；全局 R4 在小列数或 64 行输入上回退最多约 29.97%。两项均未通过。随后将候选限制为：

| 形状 | 候选内核 |
| --- | --- |
| K=2560、N≥6144、64≤T<128 | R2 |
| K=2560、N≥6144、T≥128 | R4 |
| 其他形状 | 原 R1 |

T 为输入行数，N 为输出列数。曾把 R1 合并进同一个模板，原本不应切换的形状出现约 3%～5% 回退，因此最终候选保留了原 R1 内核源码。该候选仍未应用到主线。

最终算子补测采用两个独立 A/B/A/B/A 队列，每进程 64 个用例，共 640 个计时用例。两边使用相同 128 MiB 外部工作区、all128 分配池，关闭 profiling；每例预热 16 次，取七批、每批 16 次完整引擎调用的中位数。

| 阶段／候选回合 | 格式 | 漂移合格的目标形状数 | 吞吐增量中位数 |
| --- | --- | ---: | ---: |
| 筛选／1 | FP16 | 14 | +111.44% |
| 筛选／2 | FP16 | 14 | +108.69% |
| 筛选／1 | BF16 | 14 | +110.57% |
| 筛选／2 | BF16 | 14 | +106.72% |
| 确认／1 | FP16 | 14 | +111.01% |
| 确认／1 | BF16 | 14 | +111.44% |
| 确认／2 | FP16 | 8 | +134.55% |
| 确认／2 | BF16 | 5 | +127.15% |

每回合要求相邻基线漂移≤3%、至少三个合格目标形状、中位增量≥3%，且合格形状回退不超过 3%。目标组均通过。最后一个确认回合发生基线漂移，保留 R1 的 BF16 控制组只剩两个合格形状，少于预设的三个，**完整算子门槛未通过**。所有漂移合格的控制形状仍在 −3% 以内；不能据此宣布全面无回退。确认末回合形状集合也变少，不能把其较高中位数直接与完整形状集合比较。

此前较短采样为三次预热、七批×三次调用；保留 R1 后仍出现一个 BF16/K320 控制用例 −3.26%，第二回合为 −0.85%。因此只追加了上述一次延长采样的独立补测，未继续重复算子采样。初始全局版本、通用模板和较短采样的失败记录均保留在摘要中。

## 整模型确认

IQ2_XS、同一个 Code256 提示、greedy 最多 32 个输出、INT8 KV、context 8192、prefill chunk 256、prompt cache 0，`--short-read 0` 强制批量预填。实际专家缓存始终为 4191 slots／5760 MiB；两边同为 128 MiB 预填工作区和 all128 分配池。每次为独立进程，保留已有磁盘和驱动缓存，没有清空 JIT 缓存。

复用冻结的公共引擎依赖，分别链接原 R1 与最终候选 GEMM 对象；不是完整脏工作区的全量构建，也不是与已安装生产 EXE 的比较。所有编译和 GPU 测试串行持有共享实验锁，进程检查未发现竞争任务。

第一组 A/B/A 的预填充为 16356.4／15071.4／15464.6 ms，配对增量观察值 +5.53%，但基线漂移 −5.45%，因此未确认收益。随后预先限定只做一次独立五进程确认，使用完全相同的两个 EXE：

| 顺序 | 内核 | 预填充 ms | 解码 ms |
| --- | --- | ---: | ---: |
| 0 | R1 | 16065.3 | 1489.3 |
| 1 | 候选 | 15776.4 | 1492.5 |
| 2 | R1 | 16002.4 | 1490.9 |
| 3 | 候选 | 15689.6 | 1507.7 |
| 4 | R1 | 15419.7 | 1473.3 |

相邻基线取几何均值，吞吐增量为 `sqrt(A0*A1)/B - 1`：

| 候选回合 | 预填吞吐增量 | 预填基线漂移 | 预填＋解码吞吐增量 | 结论 |
| --- | ---: | ---: | ---: | --- |
| 1 | +1.632% | −0.392% | +1.477% | 漂移合格，收益低于 3% |
| 2 | +0.119% | −3.641% | −0.039% | 漂移超限，不确认 |

八个模型进程的 32 个输出 ID 全部一致。两组模型均未通过保留门槛，没有追加模型采样，也没有采用候选。没有持续解码、普通短输入、独立 Q2 模型或 PCIe 4.0 的新结论。

## 正确性与复核

最终候选通过 5456 项检查：

| 检查 | 项数 |
| --- | ---: |
| 关闭 XMX，原有逐位对照 | 1015 |
| 开启 XMX，数值／布局及 CPU FP64 抽样 | 1015 |
| 块边界及工作区重新绑定 | 3156 |
| 超过 4 GiB 偏移 | 270 |

边界覆盖 31/32/33、63/64/65、127/128/129、255/256/257 等行数。工作区检查实际触发 R1/R2/R4，包含零容量、恰好容量、差一字节、多一字节及重新绑定后的输入变化。非有限结果和外部 guard 改写均失败。计时输入为有偏的二进制分数，完整 CPU 周期参考误差为零，新旧完整有效输出哈希相同。

随机数据的 XMX 检查沿用相对原 FP32 路径的 0.005 界限及每例八个 CPU FP64 样本；0.005 是这组输入的检查界限，不是任意模型的误差保证。私有 R2/R4 普通及边界检查的有效输出哈希与 R1 一致。本轮没有为行复用额外放宽精度。

首次扩展边界检查曾出现 51 个失败，均为未改动的混合输入 oneMKL 回退在部分大行数、带输出步长的形状上改写行间填充；有效矩阵结果一致。原始失败保留。新增 T≥31 边界覆盖随后限定为连续输出，原有布局检查保留，哈希覆盖有效元素，外部 guard 单独检查。大行数填充布局不属于新增检查范围。

候选补丁可用 `git apply --check bench/results/a770/xmx-row-reuse-candidate-2026-10-24.patch` 检查适用性。本轮只检查了补丁，没有应用。若之后采用，补丁中的检查器仍复用现有 `prefill_gemm_parity`、`prefill_xmx_gemm_check` 和 `prefill_xmx_boundary_check` CMake 入口。

原始输入、环境、构建命令、日志和模型输出留在本机。公开摘要保留所有候选的门槛状态、逐形状数值和哈希。记录审计通过表示证据可复核，不表示性能门槛通过。
