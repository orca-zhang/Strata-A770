# 启动到 READY：复用完整主机镜像

2026-11-05，Windows，Arc A770 16 GB，Xeon E5-2696 v4（22 核／44 线程），
驱动 32.0.101.9034，oneAPI 2025.3。Qwen3.8-Flash-Next IQ2_XS，Orca L0，
U4／M16／HC Q8 SG16，MTP4，完整词表 248320，最大上下文 8192。

独立复测的 READY 中位数为 **27.377 → 25.332 s，减少 2.044 s（7.47%）**。
两个交替顺序都通过预设门槛，源码保留本次修改；生产部署未切换。

`STRATA_VERIFY_ADAPT=1` 和 `STRATA_VERIFY_NO_HOST=1` 本来就需要完整主机镜像。
现在先建立它，再从稳定的镜像地址复制相同专家到相同 GPU 槽，省掉约 7.74 GiB 的重复文件读取。
保留每 64 次复制等待一次和最终等待，槽 0 仍回读校验；完整镜像不足时仍报错退出。
非完整镜像模式保留原加载路径。镜像列表用按专家编号索引的字节表替代反复扫描，保留原优先级和布局。

GPU 缓存请求 5500，实际 5771 槽／7922 MiB；主机镜像为全部 24576 专家／33.02 GiB，
`STRATA_MIRROR_MIB=49152`，显存预留 1536 MiB。两版容量相同，图准备仍在 READY 前完成。
没有新增后台加载阶段、数学内核、依赖或运行时开关。

系统文件缓存已有内容，没有清空缓存或重启；以下不代表冷盘启动。
