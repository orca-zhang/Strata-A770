# A770：IQ2_S SG16 协作读取对照

A770 16GB / PCIe3.0 / Windows / driver32.0.101.9034 / DPC++2025.3.2。**协作读取未取得收益，不接入模型。**

在[工作组大小对照](gu-schedule-2026-10-28.md)之后，保持 WG256/SG16、原始82字节 IQ2_S 块、整数点积、FP32累加、SwiGLU/Q8 和 Down。候选将每对块作为164字节读取：SG16加载41个对齐DWORD，再通过全组 shuffle 分发码字、符号、元数据及 FP16 scale。最后一次加载仅前9个 lane 有效，源码不越过164字节范围。没有预取、权重重排或额外权重字节。

原对象 A、同 helper 标量读取 C、协作读取 B 位于同一 EXE；B/C 只有权重字段读取不同。240个真实专家、八组权重，N2560/F640、GU16/Down4。mixed4/mixed8 分别每第四/第八个物理专家指针指向 pinned-host USM，其余在显存；这些是构造的驻留比例，不是模型缓存命中率。

CPU检查65536个 lane 字段组合，与独立原始字节切片一致。六个随机/大值稀疏边界进程检查288条完整链。27个计时进程保留全部1782批样本：每个 T=1–6 预热16图，每批4次48链重放，11批取中位数。1296条 eager 输出和完整 Q8 字节、27次空组、162个最终图输出、非零条目起点、分散输出、未用输出与两侧守卫均通过原对象参考检查。分派日志确认实际模式。计时含主机提交和图完成等待，不开启 profiler。
