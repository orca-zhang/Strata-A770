## 条件和流程

- A770 16 GB、Xeon E5-2696 v4、256 GiB DDR3、PCIe 3.0 x16、Windows，DPC++ 2025.3.2 / oneMKL 2025.3。
- IQ2_XS，FP16 KV，MTP4、完整草稿词表，32 MiB 工作区，short-read 1024，context / prefill 8192，提示缓存关闭。固定实际缓存 5771 slots / 7.74 GiB。
- A1 / A2 使用同一冻结生产 8 专家 EXE，B 使用首次失败时的冻结 32 专家 EXE；仅专家等待间隔不同。两份 EXE、编译证据及 API 源码哈希均核验。
- 每个新服务先预热 tool255 三次，再依次预热 tool258、1K、2K；随后完整保留三轮 1K、2K、tool258，共 15 次请求。三个私有服务退出码均为 0。
- 两把共享 GPU 锁覆盖全部测量；服务运行前已恢复 Normal 优先级。沿用 3% 门槛：受控 HTTP / prefill 和工具 decode 的基线时间漂移绝对值不得超过 3%，吞吐回退不得超过 3%，至少一个长输入 HTTP / prefill 吞吐提高 3%。
- 本轮没有重跑算子检查；复用相同候选 EXE 的 **464 项**冻结检查证据。本轮门槛未通过，未运行额外自动缓存兼容服务，未切换生产配置。
