# A770：生产专家链批量提交验证（2026-10-25）

相对已验证的[尾块生产版](xmx-tail-production-2026-10-25.md)，本轮将已有专家链和跨专家批量提交集成到生产对象中。固定容量 HTTP A/B/A 与实际自动缓存检查均通过，**本机生产启动配置已切换，下次启动服务生效**。

后续[生产 HC inject 验证](hc-production-2026-10-25.md)在此版本之上通过独立 HTTP A/B/A 与自动缓存检查，本机启动配置已再次更新。本报告保留本轮原始结果及切换快照。

## 条件与改动

Arc A770 16 GB、Xeon E5-2696 v4、256 GiB DDR3、PCIe 3.0 ×16、Windows 10；驱动 32.0.101.9034，oneAPI DPC++ 2025.3.2 / oneMKL 2025.3。Qwen3.8-Flash-Next IQ2_XS、FP16 KV、MTP4、context / prefill 8192、`--short-read 1024`、prompt cache 0、temperature 0、thinking 关闭。本地 Anthropic `/v1/messages` 非流式请求，生成的工具调用不执行。

候选仅重编译 GEMM 和预填充对象，保留其余冻结生产对象、静态链接方式及原 **32 MiB 工作区**。gate/up → SwiGLU → down 依次提交，每 8 个专家及最后不足 8 个专家的组末尾等待一次。有序队列保护反量化双缓冲、尾块补齐和输出复用；FP16 / BF16 输入、FP32 累加、原 XMX 内核及运算顺序保持一致。未重建整个当前工作区，也未捆绑 HC inject、GDN 或 INT8 实验。

本轮实际运行 **1728 项 GEMM 数值 / 布局 / 边界检查及 407 项专家链检查，全部通过**。后者覆盖完整 GU/H/Y 逐位比较、保护区、短工作区拒绝、重新绑定、混合形状和双缓冲连续复用。同步修正公开专家链检查的旧容量公式：对齐输入仅需补最后 8 行，T=9 最低空间为 40 KiB，原测试仍按整块复制要求 80 KiB。

## HTTP 完整对照

生产尾块版 A1 → 批量提交候选 B → 生产尾块版 A2，各启动新服务，均请求 5500 个专家槽位，实际为 **5771 slots / 7.74 GiB**。每服务预热三次 255-token 工具，再各预热一次原工具、1K、2K；随后按 **1K → 2K → 原工具** 交替三组。全部样本保留，无请求重试或择样。

基线为 A1、A2 各自中位数的几何平均，候选为 B 三个正式样本的中位数。HTTP 包含模板、分词、引擎计算及完整响应处理，排除服务启动；等效 prefill / decode 分别以输入 / 输出 token 数除以对应引擎时间。

| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 原工具 | 258 / 276 | 22.137 → 22.180 秒 | −0.19% | 22.23 → 22.21 | −0.09% | 26.38 → 26.29 |
| 1K 检索 | 1038 / 23 | **28.371 → 23.410 秒** | **17.49%** | **38.57 → 47.26** | **22.52%** | 16.05 → 16.01 |

工具行的负下降表示耗时略增，按噪音处理。候选 HTTP 范围：原工具 22.124～22.441 秒，1K 23.029～23.484 秒，2K 35.902～36.057 秒；范围为最小至最大值，不是置信区间。候选 prefill 中位数分别为 11.617、21.963、34.458 秒，各指标独立取中位数。

吞吐变化为 `基线耗时 / 候选耗时 - 1`，耗时漂移为 `A2 / A1 - 1`。**27 次正式请求正确，同场景完整响应去除随机消息 / 调用 ID 后一致**，包含工具参数、用量和停止原因。全部指标的基线漂移绝对值最大 **0.481%**。预设门槛全部通过：所有 HTTP / prefill 及原工具 276-token decode 控制的漂移不超过 3%，吞吐回退不超过 3%，至少一个长输入 HTTP 或 prefill 吞吐改善达到 3%。

decode 变化约 −0.15%～−0.32%，按噪音处理，**未确认 decode 提升**；短检索 decode 仅作描述。收益属于专家链与批量提交的组合，不单独分摊二者贡献，也不与历史独立实验的倍率相乘。

## 自动缓存与生产切换

正式门槛通过后，在同一 GPU 预约内另开候选服务，恢复生产自动缓存，实际为 **6416 slots / 8.60 GiB**。一次短工具预热后，各测一次原工具、1K、2K，完整响应均与正式候选一致。

| 自动缓存兼容检查 | HTTP 完整响应 | 等效 prefill tok/s | decode tok/s |
| --- | ---: | ---: | ---: |
| 原工具 | 22.836 秒 | 22.00 | 24.91 |
| 1K | 23.628 秒 | 46.78 | 16.34 |
| 2K | 36.199 秒 | 59.71 | 16.25 |

自动缓存是不同容量和预热条件下的单次兼容检查，不用于估计性能增量。本轮共 **49 次 HTTP 请求全部通过**：正式阶段 18 次预热、27 次测量，加上自动缓存阶段一次预热及三次检查；全部 `cache_n=0`，四个私有服务均以退出码 0 结束。

本机 `strata-iq2_xs.json` 仅原子更新 `exe`、匹配的 `env.STRATA_SYCL_BIN`，并显式开启 `STRATA_PREFILL_XMX_EXPERT_CHAIN=1` 和 `STRATA_PREFILL_XMX_EXPERT_BATCH=1`。原 `STRATA_PREFILL_NATIVE_XMX=1`、自动缓存、FP16 KV、MTP4、32 MiB 工作区和其余设置保留。旧配置原始字节留在本机实验目录的 `measure/production-config-before.json`，新配置另存快照，前后 SHA256 及 EXE 哈希见[逐次数据与复核摘要](xmx-batch-production-2026-10-25.json)。开关在源码中仍默认关闭；**本机下次正常启动使用新配置**。

## 排队与复核

GPU 被其他独立实验连续占用，最初轮询等待器多次未取得空档，后复用既有 Windows 目录通知等待器和共享锁入口。排队恢复均保留空计划，恢复前没有模型请求；未重采性能样本。临时提高的优先级仅用于等待，进入正式 GPU 预约后恢复普通优先级，恢复时尚未启动任何模型服务、完成请求数为零。所有 HTTP 测量使用普通调度，持有两个共享 GPU 锁。
