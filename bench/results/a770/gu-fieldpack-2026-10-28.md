# A770：IQ2_S 同字节数字段重排

A770 16GB / PCIe3.0 / Windows / driver32.0.101.9034 / DPC++2025.3.2。**字段重排两轮均未通过混合路径1%收益门槛，未接入模型。**

[SG16 连续读后分发](gu-coop-load-2026-10-28.md)没有收益后，本组改为加载时重排。每对原始82字节块仍占164字节：4字节保存两个 FP16 scale，64字节码字、64字节符号、32字节交错高位码与 nibble scale。SG16 每 lane 直接读取四个字段，不再做运行时 subgroup shuffle。没有 padding 或额外权重字节；整数点积、FP32累加、归约、SwiGLU/Q8、Down 和 WG256/SG16 保持相同。

只有 IQ2_S gate/up 重排，Down 字节保持原样。CPU先对4096个任意字节对检查全覆盖、无重叠及反向重建；每个候选 GPU 进程加载时再反向核对1536000个真实块对，共251904000字节。八个候选进程合计核对12288000个块对。所有重排及逆变换检查发生在计时外；真实模型中的加载、缓存装入和 prefill 消费者尚未接入，不能忽略其后续成本。

同一 EXE 保留原对象 A、原布局标量 helper C、重排读取 B。240个真实专家、八组权重，N2560/F640、GU16/Down4。mixed4/mixed8 每第四/第八个物理专家指针指向 pinned-host USM，其余位于显存；构造比例不代表实际模型缓存命中率。六个边界进程检查288条完整链；27个计时进程中，1296条 eager 输出及完整 Q8 字节、27个空组、162个图输出、非零起点、分散输出、未用输出及守卫均与原对象参考一致。分派和 repack 计数全部核对。

每个 T=1–6 预热16图，保留11批，每批4次48链重放，共1782批。关闭 profiler，按主机提交至图完成计时。两轮重排候选每轮同时对照相邻原对象和同代码标量256，两个混合比例都须达到至少1%吞吐提升、基线耗时漂移不超过3%。绝对吞吐变化小于0.3%按噪声处理，保留全部原值。
