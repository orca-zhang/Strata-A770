# 反引号直接处理 SIMD 掩码（2026-10-24）

原生反引号路径直接消费 SSE2 掩码，累计跨向量块的连续反引号长度，删除命中块的逐字符重查。先用 CPython `PyUnicode_FindChar` 跳过没有反引号的前缀，从首个命中处继续，不再在 Python 中分别查找单反引号、双反引号和计数。`METH_FASTCALL` 省掉调用中的临时参数元组。参数标签查找也直接从掩码取得位置；标记还原复用同一位扫描函数。

Python 回退保持原有计数和正则路径；没有增加依赖。连续长度、掩码和游标仍需保留为栈上状态，没有新增匹配缓存或文本副本。本次只验证 Windows 10 19045、Xeon E5-2696 v4、CPython 3.11.9 x64、MSVC 14.50 `/O2 /GL`；已有标记还原使用的 CPython 内部 Unicode writer 版本限制仍在。

基线是上一轮已验证的原生扫描器和 Python 单反引号计数快路径。两版完整模块和原生 DLL 分别从冻结路径加载，避免旧模块调用新扩展。最终源码固定在逻辑 CPU 42 测两轮，每轮交错执行 7 组 A/B/A，B 中位数对比两个 A 中位数的几何平均；基线漂移绝对值超过 3% 则弃用。最终两轮记录为 `timing-8.json`、`timing-9.json`，之前的候选和弃用结果保留在本机证据目录，没有覆盖。
