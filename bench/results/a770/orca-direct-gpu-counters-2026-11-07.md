# 同一 ZEBIN 的 L0 / Direct 硬件计数对照

2026-11-07，Windows 10，Intel Arc A770 16 GB，驱动 32.0.101.9034，
Xeon E5-2696 v4，VTune 2026.4，oneAPI 编译器 2025.3.2。
Orca L0 仍为推荐后端，Direct 仍为 WIP。

本轮测量运行时路径，两个冻结 EXE 均加载 full-current 的 Direct 原生包，
融合 HC Q8 为 128 GRF。未重新编译或替换产品 EXE。
这与默认 HC256 的 L0 整版本成绩不同，也不是原生产 SYCL 的新对照。
固定 Short 23 输入 tokens，自然 EOS 输出 70 tokens，spec=4、step/last min-p=0.5、
cumulative=0，实际 5771 专家槽，预留 1536 MiB，U4/min16/M16，BCS 用于 Direct 复制。
模型、MTP、U4 文件复核已有 SHA256 与文件身份/大小/时间戳缓存；未重复全量哈希大权重。

每臂新进程，固定 L0 → Direct → L0，预热 10 次，采集前 5 次，外部采集 5 次，采集后 5 次。
75/75 完整输出 tokens、结束原因、草稿采纳/提供及 reuse/resume 一致；原始协议单独回读核验。
下表不带 profiler 的结果保留每臂采集前后全部 10 次请求取中位数；外侧 L0 中位数取几何均值作对照。
净 decode 使用引擎 generated/decode_ms，排除初始化、准备和 prefill；TTFT、整请求单独测量。
profiler 不拦截 SYCL/L0 API，不抓内核二进制，不启用 CPU 内存带宽和引擎 GPU 时间戳。

硬件计数是 device-wide，覆盖采集中的完整五个请求、控制调用边界与桌面活动，
不能称为纯 decode、单 kernel 或应用独占指标。EU 活跃/停顿按 GPU core clocks 加权，
idle 为二者补数；这是执行单元平均状态，不能直接等同 CPU 提交空洞或整个 GPU 空闲。
表中读写为 VTune 描述的设备本地显存原始字节计数之和，**不是 PCIe 传输量，也不是 D2D API 复制量**。
原始 `XVE Busy` 仅表示 bin 内是否有线程，不能当作利用率百分比。
