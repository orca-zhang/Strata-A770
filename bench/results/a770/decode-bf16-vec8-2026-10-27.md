# A770：BF16 GEMV 接入实际 decode，未获得模型收益

保留原有 FMA 和归约顺序的 vector8 GEMV 已接入实际入口。128 项算子检查与原版逐位一致，21 次 Short16 请求也全部匹配冻结输出；本轮配对 decode 吞吐变化为 **−2.56%**，没有通过收益门槛，未采用，生产配置未改。

机器为 A770 16 GiB、E5-2696 v4、256 GiB RAM、PCIe 3.0 x16，oneAPI 2025.3。隔离目录为 `build-sycl-a770-decode-gemv-exact-20261027`。新入口仅覆盖使用 FP32 激活的 BF16 GEMV，例如 router、QSA indexer 和 PLE；未覆盖 IQ2/Q2 专家和融合 HC。

前一个改变归约顺序的版本通过了 128 项低误差算子检查，但实际 B1 首次 Short16 请求从第三个输出 token 开始偏离参考，已停止。不能把它的算子收益当成实际模型收益，也不能仅凭此认定完整根因。当前版本保留原版 pair FMA、两级 XOR 归约和不符合条件时的原版回退。

同一新 EXE 按 A1/B1/A2 启用关闭/开启/关闭，固定 cache5500、实际 5771 槽，原 BF16 权重不变。每个独立进程先运行两次相同请求，再保留五次。所有请求输入 23 token、完整输出 16 token，低于原始 short-read1024 阈值，因此不作为 batched prefill 结果。

| 进程 | 保留五次 decode ms | 中位数 ms |
| --- | --- | --- |
| A1 | 749.8 / 659.1 / 594.9 / 551.6 / 526.1 | 594.9 |
| B1 | 744.7 / 676.7 / 606.8 / 568.9 / 534.2 | 606.8 |
| A2 | 731.6 / 662.9 / 587.7 / 549.0 / 518.1 | 587.7 |

两侧基线中位数的几何均值为 591.289 ms，基线时间漂移 −1.210%。预先要求吞吐增幅至少 3%、基线漂移绝对值不超过 3% 才启动独立确认；收益未达门槛，因此没有启动确认。专家缓存随重复请求调整，各进程均有明显下降趋势；两次预热没有建立稳态。本表仅比较相同请求序列，不是稳态吞吐或通用 decode 结论。

此前专家形状上的独立 GEMV 提速不等于实际 IQ2/Q2 专家获得提速。本轮再次说明：需要覆盖模型实际执行的热点、保持输出及完整计算链，并用请求级数据验收。
