# A770：IQ2 / Q2 最终累计性能对照（2026-10-21）

最终累计优化提高了显存内专家链吞吐，但本机 IQ2_XS 整模型解码为 19.938 → 19.906 tok/s，变化 -0.16%，没有明显提升。显存内算子收益不能直接换算为整模型收益。

直接比较本轮三项优化之前的冻结基线与最终源码，不叠加各轮百分比。三项改动为 Q2 打包读取、Q2 gate/up 共享激活解码，以及 IQ2_XXS 打包读取与整数符号展开。

没有改为 FP16 累加，保留原有数值精度；本轮测量未复现两倍吞吐。

硬件：Intel Arc A770 16 GB、Xeon E5-2696 v4、PCIe 3.0、Windows 10，驱动 32.0.101.9034；DPC++ 2025.3.2、oneMKL 2025.3、Level Zero SDK 1.33.1。生产 EXE 和用户配置未替换。

IQ2_S / IQ2_XXS 取自 IQ2_XS 模型 layer 0 / 1；Q2_0 取自 Q2_0 模型 layer 0。三个布局均为 n_embd=2560、n_ff=640、down=Q2_0，每格式 240 个真实专家，分四组、每组 60 个。每次调用 10×token 数个条目；全单条目、每组两个、1/1/2 混合及每组 T 个覆盖不同专家复用程度。分组是构造分布，不代表实际路由占比。激活为固定种子的高斯输入，Q8 量化在计时外。

每个可执行文件通过同一驱动对象独立链接原始或最终 IQ 对象，使用未修改的公开 API。IQ2 加载实际配置的 GU16 / Down4，Q2 加载实际配置的默认 GU8 / Down8；每次清理继承的 STRATA 环境，再应用对应模型配置。

每个场景捕获 48 次完整调用，轮换四组专家；16 次图预热，11 批×4 次图重放取中位数。每格式按 A/B/A/B/A/B/A 启动七个独立进程，每个 B 对应相邻 A 耗时的几何均值，最后分别取三组 A、B 的中位数。

显存测试相邻基线最大漂移 0.88%。最终版通过 972 组与原始基线逐位一致的完整链检查，覆盖四组专家、三个 grid_groups、非零条目起点、分散输出、未使用输出及两侧哨兵；全部进程另有 189 次图计时输出核对。

## IQ2_XS 整模型生成

为隔离三项专家优化，复用原始基线的 10 月 19 日引擎库和 generate 主对象，只替换 IQ 内核对象，分别链接两个私有 EXE；这是该对象改动的隔离对照，不是整个脏工作区的重新构建或当前生产 EXE 的替换。使用 strata-iq2_xs.json 的实际运行参数和环境，只将 expert-cache 固定为 4000（实际 4191 槽），并启用运行该缓存所需的 Level Zero 放宽单次分配限制。context=8192、prompt-cache=0，保留 MTP、自适应专家交换及 PCIe 分流设置。

A/B/A/B/A 共五个独立进程。每进程先用第一条 2K 提示生成 16 token 预热，排除该请求；随后两条 2K 和一条 8K 提示各生成 64 token。速度来自 DONE 中的实测 prompt_ms / decode_ms；不含模型加载。每个 B 按相邻 A 耗时的几何均值配对，再分别取两组 A/B 耗时的中位数。

| 场景 | 输出 token | 基线 decode tok/s | 最终 decode tok/s | 吞吐变化 | 基线 prefill tok/s | 最终 prefill tok/s | prefill 变化 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 2K 提示 A | 64 | 20.884 | 20.844 | -0.19% | 221.68 | 219.94 | -0.79% |
| 2K 提示 B | 64 | 19.065 | 19.108 | +0.22% | 236.37 | 235.52 | -0.36% |
| 8K 提示 | 64 | 19.948 | 19.841 | -0.54% | 518.35 | 513.89 | -0.86% |

按三条请求的解码总耗时合并，基线 19.938 → 最终 19.906 tok/s，变化 -0.16%。整模型相邻基线最大漂移 4.85%。五进程共计 960 个计时输出 token；三条请求在所有进程中逐 token 一致：True，预热输出一致：True。

Q2_0 的默认整模型配置此前在未修改的基线上也出现停顿，稳定覆盖配置下基线重复生成也不一致，见 [此前记录](q2-packed-load-2026-10-21.md)。本轮没有将 Q2 专家链收益换算成 Q2 整模型生成速度，也不新增 Q2 生成等价性结论。
