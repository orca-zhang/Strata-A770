# A770：Q2 Down 固定五步展开

A770 16GB / PCIe 3.0 / Windows / driver 32.0.101.9034 / DPC++ 2025.3.2。**没有形状通过混合驻留的重复 1% 门槛，不接入模型。** 本组未测出新的整模型收益，35/40 tok/s 仍未达成。

[实际 eager decode 采集](decode-gpu-profile-2026-10-28.md)中，Down 占累计计算 kernel 时间的 11.328%，SG16/WG256、128 GRF，没有 spill。这是带同步诊断下的累计时间，不是正常 graph 的关键路径占比。当前 Q2_0 Down 输入维度为640、每块64、每块两个整数点积部分，四个 lane 各循环五次。本候选仅将该动态循环明确展开成五步，保持每 lane 的 `k=sub+4*iteration` 次序、整数点积、FP32 逐项相加、XOR4 归约及尾部路径。没有修改 GU、SwiGLU/Q8、权重布局或精度。

同一 EXE 的模式0调用冻结原 IQ 对象 A；模式1调用重建 helper 的原动态循环 C；模式2调用同 helper 的展开循环 B。测试真实 IQ2_S GU/Q2_0 Down、N2560/F640、GU16/Down4、240专家、八组物理权重，T1–6。mixed4/mixed8 分别令每第四/第八个物理专家走 pinned host USM，其余 device USM；它们是合成驻留比例。纯显存只作诊断。只有同时胜过原对象及同 helper 控制，才能把收益归到展开。

六个随机/大值稀疏边界进程通过组长度1–7、非零起点、分散输出、完整输出/Q8及守卫检查。按 A1/C1/B1/C2/A2/C3/B2/C4/A3 顺序、每臂三布局，共27个计时进程；每进程先核对48条 eager 完整链及六个图的输出，再对各 T 预热16图、保留11批，每批4×48链重放。共1782批，全部样本保留。这里没有宣称每个计时批后都读回所有输出，也没有用队列跨度冒充独立 kernel 时间。各形状 stderr 分派见证通过。
