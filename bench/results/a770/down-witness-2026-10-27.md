# A770 专家 Down 首个异常捕获

A770 16GB / PCIe 3.0 / Windows / DPC++ 2025.3.2。此前完整评分序列在原版和 HC Q8 上均出现间歇性非有限评分；采样曾将最早异常定位到专家 Down 或 FFN HC-down，但未保留实际 Down 权重，不能确认根因。

本组保持原始 GEMM 对象 `build-sycl-a770-hc-failure-context-20261027/candidate.obj`，U4 关闭、专家链开启、批量等待关闭。每个全新进程均先 Short16，再运行原始 followup、long 两条评分请求。探针在原始压缩权重的 ring slot 释放前保存 Q2 字节，在每个已完成的专家 Down 后扫描输出；首个坏专家保存实际解量化权重，在整层缓冲区复用前保存完整 X/GU/H/Y。无新增逐专家 host wait，但扫描、复制和分配改变调度，仅作诊断。

## layer 8 窄范围组

`build-sycl-a770-down-witness-20261027/` 只覆盖 layer 8（从 0 编号）、T7964/7993。两个进程共完成 6 次请求并退出 0；运行结束和额外终端来源/捕获审计通过。

| 进程 | 非有限评分行 | 捕获的坏专家 |
| --- | ---: | ---: |
| D1 | 0 | 0 |

D2 复现评分异常而没有 layer 8 捕获，证明这个探针范围不足以覆盖本次故障。不能据此宣称修复，也不能排除其他层、其他阶段或 verifier 内的异常。

GPU 合成检查验证有限结果不触发、NaN/Inf 触发、首个坏专家不会被后续坏专家覆盖，以及原始压缩数据和实际解量化权重在 scratch 复用后仍保留。解析器将全部实际 W 与 CPU Q2 解包逐位比较，统计完整输入和结果的非有限元素，并对最多 256 个坏输出坐标用 CPU64 复算。

## 全层组

新目录 `build-sycl-a770-down-witness-all-20261027/` 将相同两条长请求扩大到全部 48 层，每进程仅保存首个异常专家；其他形状保持不采集。复用原组的模型算术、请求、构建和解析检查，不编辑已冻结实验。另加 layer 0/47 覆盖、其他形状排除及跨层首个失败保留的合成检查。

首次预登记因 `runpy` 传入相对脚本路径而停止，尚无 protocol 或模型请求；使用绝对脚本路径后完成预登记，原 traceback 保留为 `failure.txt`。该文件不代表后续 GPU 运行的退出状态；应检查最终 `results.json`、wrapper 退出码和来源审计。

两个进程均完成 Short16 和两条长请求并退出 0。D1 评分全部有限；D2 的 long 出现 134 行非有限评分，并捕获 layer 40、T7993 内一个 1281 行专家的实际数据。

| --- | ---: |
| X / GU / H / W 非有限元素 | 全部 0 |
| Y 非有限元素 | 76 |
| 实际 W 与原始 Q2 的 CPU 解包差异 | 0，全部元素逐位相同 |

76 个输出均为 `0xffc00000`，分布于行 16–23 的两个完整 8×8 tile，分别有 48、28 个坏元素；没有坏元素处于最后的单行尾块。这个样本排除了正常 FP32 数值溢出，也没有发现捕获权重的 Q2 解包差异。快照是在对应专家完成后、缓冲区复用前保存，仍不能证明乘法执行瞬间读取的每个输入与事后快照完全相同，不能直接判定 XMX 硬件或编译器缺陷。

随后在独占锁内，用已安装 NumPy 对完整 H/W 生成 CPU64 参考，覆盖全部 3,279,360 个输出。除了 76 个非有限值，另有 **52 个有限输出**超过 `5e-6` 绝对误差，最大错误约 `7.6382e8`；完整 CPU64 输出的最大绝对值仅 `0.4562340861`。因此“输出全部有限”不足以验收这个故障，重放必须比较完整数值。

后续隔离重放目录为 `build-sycl-a770-down-replay-20261028/`：链接原始 GEMM 对象，复用实际 H/W，对比普通输出位置、原专家在 Dm 内的偏移及该偏移加 4 GiB；三处输出均在起始位置加 128 字节守卫。另比较 T1281 与裁掉末行的 T1280。每次先填充 NaN，再检查完整 CPU64 参考、原有限结果和输入/输出守卫。两个独立进程正反序执行。无速度采样；另一个 `down-inline` 诊断已完成两进程共 6 次请求，全部评分有限且没有捕获坏专家，探针改变内核指令，不能据此宣称修复。

## 实际数据重放结果（2026-10-28）

第一次重放的 forward 进程以 `0xC0000135` 退出，stdout/stderr 为空，尚未执行 GEMM；构建环境缺少模型运行时 DLL 搜索目录。完整失败协议、EXE 和日志保留。新建 `build-sycl-a770-down-replay-20261028-v2/`，改用已有 `bench_deepinfer.environment(cfg)` 的运行环境，复用完全相同的 EXE、GEMM 对象和 CPU64 参考，没有重新编译或替换失败样本。

这份输入没有复现确定性的较大偏移或末行尾块错误。重放未包含原来的 GU/SwiGLU、专家搬运线程、借用缓存布局及完整层间状态，不能排除这些上下文中的瞬时数据或执行问题，也不能将 192 次通过视为修复。完整捕获组、核内诊断组和重放组的额外终端来源审计均退出 0。
