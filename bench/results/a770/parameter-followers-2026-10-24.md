# 工具参数结束位置检查（2026-10-24）

Xeon E5-2696 v4、Windows、Python 3.11.9。此次只运行 CPU 解析及模拟引擎回归，未启动模型或占用 GPU。

`serve/frontend.py` 的 `param_end` 原来逐个检查 `</parameter>`，每次切出并复制后面的全部文本，再去掉开头空白。参数包含许多字面结束标签时，会反复复制大量文本。现在用预编译的标准库正则定位第一个后接 `<parameter=` 或 `</function>` 的结束标签；没有完整后继时，只检查最后一个候选的未完成后继。

保留原来的 Unicode 空白、逐块到达、字面标签及 `final=True` 行为。没有引入新的依赖或解析状态。

## 完整解析链计时

同进程 A/B/A，每臂 7 个样本；A 使用本轮改前快照中的 `param_end`，B 使用新实现，其他解析代码相同。输入按 8 字符分块，启用流式工具参数；每次校验完整调用和流式 JSON 参数一致。短参数每样本解析 200 次，普通长参数 3 次，其余每样本 1 次，每臂另有一次不计时的正确性预检。

基线为两臂 A 中位数的几何平均；A 漂移绝对值超过 3% 的组排除收益结论。两轮原始数据全部保留。

优化仍会搜索累计缓冲区，没有消除整个流式解析链的最坏复杂度。以上属于 CPU 解析阶段，未新增模型 prefill、decode 或 HTTP 端到端测量，未加入 README 性能表。
