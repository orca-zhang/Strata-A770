# A770：IQ4_XS 逐字解包与点积融合

A770 16GB / PCIe3.0 / Windows / DPC++2025.3.2。**保持原精度的融合版本在四种真实矩阵上均变慢，不接入模型。** 本实验来自[实际 decode 剖析](decode-gpu-profile-2026-10-28.md)中原生 MMVQ 的热点与 spill 记录；没有获得新的整模型收益。

候选对三至八列将原先展开的权重解包与点积改为四次不展开的逐字循环，解出 nibble 后立即执行各列整数点积。保留 SG32、WG128、原始权重布局、字节数、整数点积、FP32 缩放和 XOR32 归约。原版为 A，使用相同新 helper 但保留原运算体的控制为 C，融合候选为 B；一、二列保持原版，仅作诊断，不参与候选筛选。

第一版在输入2560、输出7行、三列的边界检查出现10个不相等输出，最大绝对差为1.19209289551e-7。这只是首次失败边界的诊断，不是全模型误差上限。第二版将每块缩放保留在独立返回表达式中，再进行累加，匹配原版 `F::apply` 的表达式边界；不放宽正确性门槛。该修正与浮点乘加收缩差异一致，未以机器指令证明其唯一原因。

第二版九个边界进程覆盖输入512/768/2560、输出7行、列数1–8，576项完整 eager 输出检查通过。36个计时进程各检查48项 eager 和6项 graph 完整输出，共1728项 eager 和216项 graph；包括守卫、未使用列和有限值检查。四种权重直接复用已核验的真实 GGUF 提取，每种使用八个独立 device USM 副本，不模拟 host USM 专家缺失。

顺序为 A1/C1/B1/C2/A2/C3/B2/C4/A3，每臂测试四种矩阵和一至六列。每列预热16图，保留11批、每批4次48-kernel图重放，共2376批。计时包含主机提交和图完成，关闭 profiler。收益使用相邻基线耗时的几何均值计算；两轮相对 A/C 均须至少提升1%，基线漂移不超过3%；绝对吞吐变化低于0.3%视为噪音，保留原数值。

所有活跃列相对原版的基线漂移均不超过1.372%。首轮相对 helper 的输出头三/四/五/六列、QKV四/六列漂移超过3%，这些配对排除；一列也有超限诊断记录，完整保留。其余配对同样没有正收益，不能把整体回退归为噪音。尚未采集本候选实际 GRF、spill 或原生指令，不能断言变慢的具体原因。
